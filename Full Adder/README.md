# Full Adder Verification using SystemVerilog

## Overview

This project implements a synchronous 3-bit Full Adder in SystemVerilog and verifies its functionality using a custom mailbox-based SystemVerilog testbench. The verification environment consists of a Generator, Driver, Monitor, Environment, and Scoreboard to automatically validate the DUT output.

## Features

- Synchronous 3-bit Full Adder RTL
- Mailbox-based verification environment
- Randomized stimulus generation
- Automatic output checking using a scoreboard
- PASS/FAIL reporting for each transaction

## Verification Flow

```
Generator → Driver → DUT → Monitor → Scoreboard
```

## Tools Used

- SystemVerilog
- QuestaSim
- VS Code

## Result

The monitor captures the DUT output and forwards it to the scoreboard. The scoreboard computes the expected result, compares it with the DUT output, and reports **PASS** or **FAIL** for every transaction.
